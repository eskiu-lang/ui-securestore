## `<securestore>`

`<securestore>`: small secrets kept by the platform's secure storage, for apps on
eskiu-lang/ui: a session token, a refresh token, a key. The iOS Keychain (this device only,
readable after the first unlock), and on Android values encrypted with an AES-GCM key held by
the Android Keystore, the key never leaving it. The web and the desktop have no such store:
there a value goes to localStorage, in the clear (secure_is_secure says so).

```eskiu
secure_set("session", token);
string saved = secure_get("session");    // null when there is none; free it
defer free(saved);
```

### secure_get

```eskiu
string secure_get(string key)
```

The value kept under `key`, a copy the caller frees, or null when there is none.

### secure_set

```eskiu
bool secure_set(string key, string value)
```

Keeps `value` under `key`, replacing what was there; false when the platform refused.

### secure_remove

```eskiu
bool secure_remove(string key)
```

Forgets `key`; true when nothing is kept under it afterwards.

### secure_is_secure

```eskiu
bool secure_is_secure()
```

Whether values are kept encrypted by the platform (iOS, Android), not in the clear (web).
