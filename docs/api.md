## `<securestore>`

`<securestore>`: small secrets kept by the platform's secure storage, for apps on
eskiu-packages/ui: a session token, a refresh token, a key. The Keychain on iOS and macOS,
values encrypted with an AES-GCM key held by the Android Keystore on Android, the Secret
Service (GNOME Keyring, KWallet) through libsecret on Linux, and DPAPI on Windows. The web,
and the desktop's webview builds, have no such store: there a value goes to localStorage, in
the clear, and secure_is_secure is false. On Linux without libsecret or a running Secret
Service, set and get fail and secure_is_secure is false; nothing is written in the clear.

```eskiu
secure_set("session", token);
string saved = secure_get("session");    // null when there is none; free it
defer free(saved);
```

### secure_get

```eskiu
string secure_get(string key)
```

The value kept under `key`, a copy the caller frees, or null when there is none.

### secure_set

```eskiu
bool secure_set(string key, string value)
```

Keeps `value` under `key`, replacing what was there; false when the platform refused.

### secure_remove

```eskiu
bool secure_remove(string key)
```

Forgets `key`; true when nothing is kept under it afterwards.

### secure_is_secure

```eskiu
bool secure_is_secure()
```

Whether values are kept encrypted by the platform: true on iOS, Android, macOS, Windows,
and Linux with a Secret Service; false on the web and in webview builds (localStorage, in
the clear) and on Linux without one (set and get fail there).
